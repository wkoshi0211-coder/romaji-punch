# ローマ字パンチ！

ひらがなからローマ字を思い出す、キーボード練習ゲーム。

**あそぶ:** https://wkoshi0211-coder.github.io/romaji-punch/

## あそびかた

1. 「１文字れんしゅう」で行を選ぶか、「ことばれんしゅう」で条件を選びます。
2. 半角英数で入力します。日本語入力（IME）はオフにしてください。
3. １問正解で１パンチ。10問でクリアです。時間制限・減点はありません。
4. ヒントを押すとローマ字とキーの位置が表示されます。

`si/shi`、`ti/chi`、`tu/tsu`などの入力に対応。間違いキーは無視し、Backspaceで入力途中を戻せます。

単語の初期設定は２文字、特殊文字なしです。「あり」にすると「ん」「ー」「っ」「ゃゅょ」を個別に選択できます。長い言葉には「２〜５文字」を選んでください。

## 開発

HTML/CSS/JavaScriptのみ。外部依存、外部画像、解析、記録保存はありません。キャラクターはCSSで描いたオリジナルです。

`index.html`をブラウザで開くか、静的HTTPサーバーで配信してください。GitHub Pagesは`main`のルートを配信します。

- `app.js`: メニュー、問題、ヒント、音、演出
- `romaji.js`: 複数の入力候補を並行して判定する入力エンジン
- `style.css`: レイアウト、キャラクター、アニメーション

Windows/Chromebookの物理キーボード向け。Chromebook実機での検証は未実施です。
